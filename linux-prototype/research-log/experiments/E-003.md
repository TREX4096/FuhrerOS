# E-003 — validation of the revised class→policy map (D-006 rev. 2)

**Directory:** `experiments/E-003-main-20260926-0845/`
**Question:** With `IO_SEQUENTIAL→SPECIALIZED` and `CPU_BOUND→NORMAL`, does adaptive (B2) reach the best static policy (B3)?
**Hypothesis:** H3 — B2 within ±10 % of B3 on every storage workload.
**Setup:** as E-002 (bench VM, KVM nested in WSL2, kernel 6.12.111), workloads randread, seqread, randwrite, seqwrite and cpu; 10 s runs with 5 s warm-up.
All 8 configurations ran (F-006).

**Procedural note:** the run was **aborted during repetition 3** when the controlling
Claude Code session ended. B0 had completed 3 reps. For the FuhrerOS boot, 2 complete reps per
configuration were recovered afterwards from the VM's disk; the partial third rep is excluded.
The salvage was a separate boot that only copied files, with no measurements. **n = 2** for all
FuhrerOS configurations.

## Results (medians; CV % in parentheses)

| workload | B1 normal | static specialized (B3) | B2 adaptive | B2 vs B3 | E-002 B2 vs B3 (old map) |
|---|---|---|---|---|---|
| randread IOPS | 730 (55 %) | 11,040 (8 %) | 11,144 (8 %) | +0.9 % | −10.3 % |
| randwrite IOPS | 2,683 (37 %) | 8,501 (22 %) | 10,862 (24 %) | +27.8 % | +7.1 % |
| seqread MB/s | 53.2 (109 %) | 768.7 (3 %) | 817.4 (2 %) | +6.3 % | −87.0 % |
| seqwrite MB/s | 44.8 (69 %) | 718.9 (8 %) | 802.2 (9 %) | +11.6 % | −91.6 % |
| cpu Mops/s | 1,093 (40 %) | 1,529 (17 %) | 1,714 (19 %) | +2.2 % vs batched | −10.6 % |

## Interpretation
- **H3 supported** for the storage workloads. The revised map closes the sequential-I/O gap
  (−87 % → +6 %, −92 % → +12 %).
- Adaptive "above B3" should be read as *equal within noise*: n = 2, and CVs overlap.
  One plausible real effect in randwrite: adaptive starts from NORMAL and uses buffered writes
  until it switches, and the page cache absorbs those. This is **UNKNOWN — REQUIRES VERIFICATION**.
- CPU: the spread between configurations (B0 1,966 vs B1 1,093 with CV 40 %) is host
  interference, not policy. No CPU policy claim is made.
