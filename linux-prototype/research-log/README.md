# Research log

- `decisions/` — pointers to decision records (the records live in `docs/decisions.md`)
- `experiments/` — E-XXX records (question, hypothesis, setup, result, interpretation)
- `failures/` — F-XXX records (symptom → root cause → fix → regression test → lesson)

Rule: nothing here is reconstructed after the fact without saying so. If the
reason for something is not known it is written as
`UNKNOWN — REQUIRES VERIFICATION`.
