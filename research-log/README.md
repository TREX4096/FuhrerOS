# Research log (from-scratch kernel)

- `decisions/` - index of decision records (full text: docs/decisions.md)
- `experiments/` - E-1xx records
- `failures/` - F-1xx records (symptom -> root cause -> fix -> regression test -> lesson)

Records of the earlier Linux-based prototype (D-0xx, E-00x, F-00x) are kept in linux-prototype/.
Nothing here is reconstructed after the fact without saying so.
