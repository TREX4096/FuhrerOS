# E-121 — `micro` (superseded)

- **Question:** NEW_EXPLANATION §35: reproducible CPU, memory, storage, network and desktop micro-benchmarks.
- **Hypothesis:** No hypothesis: a baseline of what the system does.
- **Host:** Linux 6.6.87.2-microsoft-standard-WSL2 x86_64; AMD Ryzen 5 7520U with Radeon Graphics (Windows 11 -> WSL2 -> QEMU; KVM nested inside WSL2 when accel=kvm)
- **Guest:** FuhrerOS, 4 vCPU offered / 1 used, 4096 MB
- **QEMU:** QEMU emulator version 10.2.1 (Debian 1:10.2.1+ds-1ubuntu3.1), accel KVM; virtio-blk, FFS0 raw image, host cache=writeback; virtio-net, QEMU user-mode (slirp)
- **Kernel:** FuhrerOS 0.1.0 (own kernel), commit `fceac52-dirty`, 2026-09-26T18:04:15Z
- **Workload:** fubench cpu/mem/storage/net x3, then fubench desktop once (it starts the compositor).
- **Policy / configuration:** `rootfs/etc/bench/micro.sh` (copy in the run directory)
- **Metrics:** time, rate or latency per benchmark (units in summary.md); NOT RUN where impossible
- **Result:** seq_write 1.82 MB/s, seq_read 366.09 MB/s, rand_write 842 ops/s, small files 230/s; UDP: 20000 sent, 32 received (unpaced sender).
- **Variance:** see CV% columns in [summary.md](../../experiments/E-121-micro-20260926-1803/summary.md)
- **Interpretation:** Superseded. Exposed F-123 and the unpaced UDP benchmark.
- **Threats:** nested virtualisation (Windows → WSL2 → KVM); one CPU used; few repetitions; synthetic workloads.
