# E-130 — `cache` (final)

- **Question:** RQ5: does the adaptive buffer cache improve storage throughput over fixed policies?
- **Hypothesis:** Adaptive matches read-ahead on sequential reads and LRU on re-use workloads.
- **Host:** Linux 6.6.87.2-microsoft-standard-WSL2 x86_64; AMD Ryzen 5 7520U with Radeon Graphics (Windows 11 -> WSL2 -> QEMU; KVM nested inside WSL2 when accel=kvm)
- **Guest:** FuhrerOS, 4 vCPU offered / 1 used, 4096 MB
- **QEMU:** QEMU emulator version 10.2.1 (Debian 1:10.2.1+ds-1ubuntu3.1), accel KVM; virtio-blk, FFS0 raw image, host cache=writeback; virtio-net, QEMU user-mode (slirp)
- **Kernel:** FuhrerOS 0.1.0 (own kernel), commit `4768a1f`, 2026-09-26T18:24:30Z
- **Workload:** iobench on a 64 MiB file through a 1024-block (4 MiB) cache: seq, random, hotset (80 % in 2 MiB), scan (hotset + sequential scan). 6 s per run, 2 repetitions, reversed order in the second.
- **Policy / configuration:** `rootfs/etc/bench/cache.sh` (copy in the run directory)
- **Metrics:** MB/s, hit rate, read latency p99, cache CPU, read-ahead issued/used
- **Result:** Throughput MB/s - sequential: LRU 21.18, FIFO 22.42, CLOCK 21.53, read-ahead 342.97, adaptive 301.04; random: 23.15-25.24 (adaptive highest); hotset: LRU 100.91, FIFO 64.10, CLOCK 95.20, read-ahead 101.23, adaptive 93.47; scan: LRU 35.14, FIFO 31.84, CLOCK 33.88, read-ahead 27.56, adaptive 26.37. Hit rate sequential 999 per mille for read-ahead and adaptive, 744 for LRU.
- **Variance:** see CV% columns in [summary.md](../../experiments/E-130-cache-20260926-1824/summary.md)
- **Interpretation:** RQ5: partly. On sequential reads adaptive reaches 88 % of the dedicated read-ahead policy and 14.2x LRU with the same 1024 blocks; on random reads it is the best. On re-use workloads it is below the best fixed policy: hotset about 8 % below read-ahead and LRU, scan 25 % below LRU. With the F-123 fix every miss is cheaper, so absolute numbers are higher than in E-118 but the ranking is the same.
- **Threats:** nested virtualisation (Windows → WSL2 → KVM); one CPU used; few repetitions; synthetic workloads.
- **Next experiment:** Make the adaptive cache fall back to plain LRU on scan/hotset patterns.
